# 年度練習題庫

103～115 年共 390 題，每年 24 題選擇、6 題看解釋填成語。每場隨機抽 8 題選擇（各 10 分）與 4 題填成語（各 5 分），滿分 100 分、60 分通關。

填成語答案逐字比對，不接受額外空白、標點、錯字或同義成語；不呼叫 AI。抽出的題目與選項順序會隨本機存檔保存。

每年度先涵蓋 8 個候選詞條；並非全部來源成語。例句是新增改編練習，不是官方歷屆原題。所有題目仍為 needs_review，尤其語境選項需由教師確認是否存在多解。

`年度題庫審核表.csv` 可用試算表開啟；`annual-390.json` 為相同內容的結構化版本。使用 `node scripts/export-question-bank.mjs` 重建兩者。未包含學生名冊或上傳原始附件。
